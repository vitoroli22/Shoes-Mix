# 👟 ShoesMix

Sistema web de comércio eletrônico voltado para a venda e gerenciamento de calçados.

O ShoesMix tem como objetivo disponibilizar uma plataforma digital que facilite a comercialização de produtos, permitindo que clientes realizem compras de forma organizada e prática, enquanto a equipe administrativa possui recursos para gerenciamento de produtos, pedidos, estoque e devoluções.

---

# 📌 Sobre o Projeto

O projeto foi desenvolvido como trabalho da disciplina de **Gerência de Configuração** do curso de **Engenharia de Software da Universidade Federal do Amazonas (UFAM) - ICET**.

A aplicação busca auxiliar pequenas lojas de calçados na inserção no ambiente digital, oferecendo recursos para apresentação de produtos, realização de compras e organização das operações internas.

---

# 🎯 Objetivo

Desenvolver uma plataforma web que permita:

- Divulgação e venda de calçados;
- Organização dos produtos disponíveis;
- Gerenciamento de pedidos;
- Controle de estoque;
- Administração de usuários e permissões;
- Melhor experiência de compra para os clientes.

---

# 👥 Usuários do Sistema

## 🛒 Usuário Comum

Responsável pela interação de compra.

Principais funcionalidades:

- Cadastro e login;
- Pesquisa de produtos;
- Filtragem por categorias;
- Adição de produtos ao carrinho;
- Realização de compras;
- Acompanhamento de pedidos;
- Solicitação de devoluções;
- Gerenciamento de informações pessoais.

---

## 📦 Gerente

Responsável pelo gerenciamento operacional da loja.

Principais funcionalidades:

- Cadastro e edição de produtos;
- Controle de estoque;
- Visualização de pedidos;
- Atualização de status dos pedidos;
- Análise de solicitações de devolução.

---

## 🔐 Administrador

Responsável pelo controle geral do sistema.

Principais funcionalidades:

- Gerenciamento de produtos;
- Controle de usuários gerentes;
- Gerenciamento de permissões;
- Consulta do histórico de alterações.
